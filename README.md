# Mandelbrot Set Numerical Computing Project

This repository contains a Python implementation of the Mandelbrot set developed as part of a numerical computing mini project. The goal of the project is to compute and visualize the Mandelbrot fractal while comparing the performance of different implementation approaches.

## Overview

The Mandelbrot set is generated by iterating the complex quadratic mapping:

$z_{i+1} = z_i^2 + c$

for each point `c` in a region of the complex plane. The algorithm measures how quickly the magnitude of `z` diverges beyond a threshold. The normalized escape iteration value M(c) is then used to visualize the fractal.

The implementation evaluates a grid of complex values within the region:

- Real axis: -2 to 1  
- Imaginary axis: -1.5 to 1.5  

The result is stored as a matrix representing the escape behavior of each point, which can be visualized as the Mandelbrot fractal.

## Implementations

Three different approaches were implemented and compared:

- **Naive Python implementation** using nested loops
- **NumPy vectorized implementation** using array operations
- **Numba JIT implementation** using just-in-time compilation

Each method computes the same Mandelbrot set but differs in computational efficiency.

## Benchmarking

To evaluate performance, execution time was measured for different grid resolutions ranging from 1024 up to 8192 points. The runtime of each implementation was recorded and stored for analysis.

The benchmark results include:

- Execution time for each implementation
- Speedup relative to the naive Python implementation
- Runtime scaling as the grid resolution increases

These timings allow a comparison of how different numerical computing techniques affect performance.

## Visualization

The Mandelbrot set and benchmarking results are visualized using Python plotting tools. The fractal image shows the normalized escape values across the complex plane, while additional plots illustrate the runtime behavior and speedup of each implementation.

## Project Structure

- Mandelbrot implementations in Python
- Benchmark scripts for runtime measurement
- Visualization of fractal output and performance results
- Analysis performed in a Jupyter Notebook

## Purpose

The project demonstrates how different numerical computing techniques such as vectorization and just-in-time compilation can significantly improve the performance of computationally intensive algorithms.
